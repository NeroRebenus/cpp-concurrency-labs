# Readers–Writer Lock (RWLock)

`RWLock` - readers–writer lock: одновременно допускает **несколько читателей** или **одного писателя**.

## Интерфейс

- `Read(func)` - выполняет `func()` в режиме чтения.
- `Write(func)` - выполняет `func()` в режиме записи.

Callback-стиль удобен для автоматического освобождения блокировки даже при исключениях.

## Реализация (writer-preference)

- Состояние: число активных читателей (`blocked_readers_`) и число ожидающих/активных писателей (`blocked_writers_`).
- Читатели блокируются, если есть хотя бы один писатель в ожидании/работе.
- Писатель ждёт, пока активные читатели закончат.

Эта стратегия предотвращает голодание писателей ценой возможного голодания читателей при постоянном потоке писателей.
