# MPMC Bounded Queue (Fast Queue)

`MPMCBoundedQueue<T>` - bounded MPMC очередь (multiple producers / multiple consumers), неблокирующая:

- `Enqueue` возвращает `false`, если очередь заполнена.
- `Dequeue` возвращает `false`, если очередь пуста.

## Идея

Очередь реализована как кольцевой буфер, где каждый слот хранит:

- значение `T`
- атомарный счётчик поколения (sequence/generation)

Два глобальных атомарных индекса (`begin_` и `end_`) двигаются независимо. Слот доступен для записи/чтения, если его поколение совпадает с ожидаемым значением (по описанному в задании протоколу).
