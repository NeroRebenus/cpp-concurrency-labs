# Futex Mutex

`Mutex` - мьютекс, реализованный на атомарном состоянии и `futex` (fast userspace mutex).

## Интерфейс

- `void Lock()`
- `void Unlock()`

## Идея

- Быстрый путь: попытка захватить мьютекс через `compare_exchange` без перехода в ядро.
- Медленный путь: при конкуренции поток засыпает через `FutexWait`, а при `Unlock` один ожидающий пробуждается через `FutexWakeOne`.
