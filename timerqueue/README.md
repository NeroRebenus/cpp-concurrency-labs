# TimerQueue

`TimerQueue<T>` - примитив синхронизации, который хранит множество пар (v, t), где v - значение, а t - момент времени (`std::chrono::system_clock::time_point`).

## Поведение

- `Add(v, t)` добавляет элемент.
- `Pop()` блокируется до момента `min(t)` по всем элементам и затем возвращает элемент с минимальным `t` (при этом удаляя его).
- Если множество пустое, `Pop()` ждёт бесконечно.

## Реализация

- Хранилище: `std::set<std::pair<T, TimePoint>>` с компаратором (сначала по времени, затем по значению) для детерминированного порядка.
- Синхронизация: `std::mutex` + `std::condition_variable`.
- `Add`: вставка в set и `notify_all()`.
- `Pop`: под мьютексом
  - если set пуст - `wait()`,
  - если ближайшее время ещё не наступило - `wait_until(deadline)`,
  - если наступило - извлечение и удаление первого элемента.
