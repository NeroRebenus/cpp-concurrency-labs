# Buffered Channel

`BufferedChannel<T>` - буферизированный канал в стиле Go: несколько потоков могут одновременно писать в канал и несколько потоков - читать, без внешней синхронизации.

## Интерфейс

- `BufferedChannel(int capacity)`
- `void Send(const T& value)` - блокируется, если буфер заполнен, бросает `std::runtime_error`, если канал закрыт.
- `std::optional<T> Recv()` - блокируется, если буфер пуст, после закрытия дочитывает остаток и затем возвращает `std::nullopt`.
- `void Close()` - закрывает канал.

## Реализация

- Хранилище: `std::queue<T>` фиксированной ёмкости.
- Синхронизация: `std::mutex` + две `std::condition_variable` (для отправителей и получателей).
- Для снижения риска голодания отправителей дополнительно ведётся очередь ожидания отправителей (по меткам времени), чтобы будить их в порядке постановки в ожидание.
