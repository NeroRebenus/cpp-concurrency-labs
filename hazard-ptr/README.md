# Hazard Pointer (упрощённая реализация)

Hazard Pointers - схема безопасного управления памятью для lock-free алгоритмов: поток, читающий указатель, помечает его как "защищённый", и удаление объекта откладывается до тех пор, пока он не исчезнет из множества защищённых.

## Интерфейс

- `RegisterThread()` / `UnregisterThread()` - регистрация потока.
- `template <class T> T* Acquire(std::atomic<T*>* ptr)` - атомарно читает `*ptr` и публикует прочитанный указатель как защищённый.
- `Release()` - снимает защиту.
- `template <class T> void Retire(T* value)` - откладывает удаление объекта.

## Как устроено

- У каждого потока есть `thread_local std::atomic<void*> hazard_ptr`.
- Зарегистрированные потоки хранятся в `threads` (под `threads_lock`), чтобы сканирующий поток мог собрать список защищённых указателей.
- `Retire` добавляет запись в lock-free список `free_list`, при достижении порога запускается `ScanFreeList()`, которая:
  1) забирает все retired-указатели,
  2) снимает "срез" множества hazard pointers,
  3) удаляет то, что не защищено, и возвращает защищённые элементы обратно в `free_list`.
