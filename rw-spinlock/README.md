# Read–Write Spinlock

`RWSpinLock` - spinlock, который допускает конкурентные чтения и эксклюзивную запись.

## Идея представления состояния

Используется одна атомарная переменная:

- младший бит - флаг записи
- остальные биты - счётчик читателей (в шагах по 2)

Инварианты:

- `LockRead`: запись не активна (LSB = 0)
- `LockWrite`: запись активна и читателей нет

## Интерфейс

- `LockRead()` / `UnlockRead()`
- `LockWrite()` / `UnlockWrite()`
