# Semaphore

Семафор допускает одновременный вход в критическую секцию не одного, а `n` потоков. В этой задаче порядок выхода из `Enter()` должен совпадать с порядком входа (FIFO), чтобы исключить голодание.

## Интерфейс

- `Semaphore(int count)` - инициализация счётчика.
- `Enter(callback)` / `Enter()` - вход в критическую секцию (внутри атомарно уменьшает счётчик).
- `Leave()` - выход (увеличение счётчика на 1).

`Enter` принимает callback только для тестирования: он вызывается под защитой мьютекса и выполняется атомарно относительно других `Enter`.

## Идея реализации

- Используется `std::condition_variable` и счётчик доступных разрешений.
- Для честности ведётся очередь ожидания: каждому входящему потоку ставится "метка" (timestamp), и поток ждёт не только `count_ > 0`, но и того, что он первый в очереди.
